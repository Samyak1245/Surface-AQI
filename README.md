# Surface-AQI

Development of Surface AQI and Identification of HCHO Hotspots over India using Satellite Data.

## Objectives

1. Estimate surface air quality using satellite and reference data.
2. Identify HCHO hotspots over India.
3. Study the relationship between HCHO, fire activity, and air quality.
4. Build an interactive dashboard for visualization.

## Planned Technologies

- Python
- Google Earth Engine
- Pandas
- NumPy
- GeoPandas
- Scikit-learn
- PyTorch
- PostgreSQL/PostGIS
- FastAPI
- React
- Leaflet
